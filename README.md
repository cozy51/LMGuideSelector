# LM Guide Engineering Studio

機械設計者向けのLMガイド初期設計支援Webアプリです。装置レイアウト、複数搭載物、重心、駆動位置、加減速条件からブロック別荷重、静的安全係数、距離加重平均荷重、定格寿命、候補比較、レイアウト感度を計算します。

> 本ツールはメーカー公式Designerの代替ではありません。計算結果は初期設計、荷重分布の可視化、候補比較、パラメータスタディ用です。最終選定はメーカー最新カタログ、技術資料、公式選定ツールで確認してください。

## 起動

```bash
npm install
npm run dev
npm test
npm run build
```

Windows PowerShellでスクリプト実行ポリシーにより`npm.ps1`が拒否される場合は、システム設定を変更せず`npm.cmd run dev`等を使用できます。

## 座標系・符号規約

右手直交座標系です。

- `+X`: LMガイド移動方向
- `+Y`: 基本姿勢の上方向
- `+Z`: 横方向
- 正モーメント: 右ねじ則
- `MA = Mz`: ピッチング
- `MB = My`: ヨーイング
- `MC = Mx`: ローリング

重力ベクトルは姿勢により自動変更します。

| 姿勢 | 重力加速度ベクトル |
|---|---|
| 水平 | `(0, -g, 0)` |
| 垂直 | `(-g, 0, 0)` |
| 壁掛け | `(0, 0, -g)` |

`g = 9.80665 m/s²`です。同じ規約を`src/calculations/coordinateSystem.ts`と画面の「計算根拠」に記載しています。

## 内部単位

計算内部はSI単位です。

- 長さ: m
- 質量: kg
- 力: N
- モーメント: N·m
- 速度: m/s
- 加速度: m/s²
- 時間: s

画面境界でmm、mm/s、km、hへ変換します。変換は`src/utils/unitConversion.ts`に集約しています。

## 計算モデル

### 質量と重心

`m_total = Σm_i`

`r_g = Σ(m_i r_i) / Σm_i`

各搭載物の重力・慣性力を個別作用点に適用するため、合成重心だけに置換してモーメント情報を失うことはありません。

### 力とモーメント

- 重量: `W = m g`
- 慣性力: `F_i = -m a`
- モーメント: `M = r × F`

自動駆動力モードでは、X方向の重力・慣性力を釣り合わせる駆動力を指定駆動作用点へ適用します。重心と駆動作用線の差によるピッチ／ヨーモーメントが残ります。手動モードでは入力駆動力を使用します。

### 動作フェーズ

停止、正方向加速、正方向定速、正方向減速、負方向加速、負方向定速、負方向減速の7状態を評価します。台形速度プロファイルから加速・定速・減速距離を求めます。加減速距離がストロークを超える場合は三角プロファイルとして距離を按分し、警告します。

### ブロック配置

標準2レール×各2ブロックは次の座標です。

| ブロック | X | Z |
|---|---:|---:|
| Block 1 | `-BS/2` | `-RS/2` |
| Block 2 | `+BS/2` | `-RS/2` |
| Block 3 | `-BS/2` | `+RS/2` |
| Block 4 | `+BS/2` | `+RS/2` |

### 荷重分配

反力について次の静的釣合いを満たす最小ノルム解を計算します。

- `ΣR = -F`
- `Σ(r × R) = -M`

Y方向反力は合計荷重、ロール`Mx`、ピッチ`Mz`を、Z方向反力は合計横荷重、ヨー`My`を分担します。X反力はブロックへ均等分配します。単純な全ブロック均等割りではなく、BS、RS、偏心、加減速方向を反映します。

数学的に支持できないモーメントは架空の反力に変換せず、平衡残差として警告します。負のY反力はゼロへ切り捨てず、逆ラジアル荷重／浮き上がり傾向として保持します。

### 対応レイアウト

- 1レール×1ブロック: 集中力を計算。ブロック単体モーメント定格は別途確認
- 1レール×2ブロック: BS方向分配
- 2レール×各1ブロック: RS方向分配
- 2レール×各2ブロック: 3方向力・モーメント分配の標準対応
- 1～4レール、各1～4ブロック: 等間隔配置の一般平衡解

## 等価荷重

製品には`radialFactor`、`reverseRadialFactor`、`lateralFactor`を保持します。等価荷重ロジックは`EquivalentLoadStrategy`としてUIから分離しています。

初期サンプルは汎用方向係数1.0の加算モデルです。これはメーカー公式のシリーズ固有式ではありません。実製品を登録するときはメーカー資料に基づくストラテジーを追加してください。不明な式を推測して実製品に適用しないでください。

## 静的安全係数

`fs = C0 / Pmax`

全フェーズ・全ブロックの等価荷重最大値を`Pmax`とします。`fs >= fs_required`で適合です。

## 平均作用荷重

停止状態は走行距離が0のため、走行距離ベースの平均荷重には含めません。ただし`Pmax`と静的安全率の評価には含めます。

ボール:

`Pm = [Σ(P_i³ L_i) / ΣL_i]^(1/3)`

ローラー:

`Pm = [Σ(P_i^(10/3) L_i) / ΣL_i]^(3/10)`

各ブロックごとに計算し、最も大きな平均作用荷重を寿命評価に使用します。

## 定格寿命と寿命時間

ボールの既定式:

`L = [C / (fw Pm)]³ × 50` `[km]`

ローラーは独立ロジックで指数`10/3`、基準距離100 kmの参考式を実装しています。実製品ではシリーズ固有仕様を必ず確認してください。

- 1往復距離: `2 ST`
- 1時間走行距離: `2 ST × n × 60`
- 寿命時間: `Lh = L / 1時間走行距離`

走行頻度が0の場合、Infinityを表示せず未算出値として扱います。

## 製品候補ランキング

優先順位は次のとおりです。

1. 要求静的安全率を満足
2. 要求寿命を満足
3. ブロック断面がコンパクト
4. 安全率・寿命の過剰余裕を抑制

初期マスタの`TEST15`～`TEST35`はすべて架空値で、画面に「サンプルデータ」と表示します。実在メーカー値は登録していません。

## 製品データ追加

`src/productData/sample-products.json`と計算ロジックは分離されています。画面からCSVもインポートできます。テンプレートは「CSVテンプレート」ボタンで取得できます。

主な列:

`manufacturer, series, model, size, rollingElement, loadType, C_N, C0_N, blockWidthMm, blockHeightMm, blockLengthMm, railWidthMm, massKg, officialUrl, dataSource, verifiedDate, dataQuality`

配列列を追加する場合は`|`区切りです。データ品質は`official`、`manualVerified`、`unverified`、`sample`のいずれかです。公式URL、選定ツール、CAD、カタログURLは登録されている場合だけ表示します。

実メーカー値を追加する際は、出典URL、確認日、データ品質を必ず保存してください。Webスクレイピングには依存しません。

## レイアウト最適化・感度解析

- BSまたはRSを50～450 mmでスイープ
- `Pmax`、静的安全係数、寿命時間を同時表示
- 質量、重心高さ、重心横偏心、BS、RS、速度、加速度、fwを±20%で解析

解析は元入力を変更せず、条件のコピーへ純粋計算を適用します。

## 仮定と未対応条件

現在の計算は剛体・準静的・等間隔支持モデルです。以下は未対応または要メーカー確認です。

- ブロック／レール／ベース／テーブルの弾性変形
- 取付面剛性、平行度、取付誤差による内部荷重
- 各ブロックの剛性差と接触変形に基づく不静定荷重配分
- 転動体ごとの内部荷重分布、接触角
- レール継ぎ、局所変形、ボルト強度
- ブロック単体モーメント定格を含む寿命評価
- 予圧荷重による寿命補正
- 温度、硬さ、信頼度、潤滑、汚染などメーカー固有補正
- メーカー固有等価荷重式と基準走行距離
- 外力の任意3方向作用点を複数登録する機能
- 駆動摩擦、ケーブルベア、加工反力の自動モデル

予圧データがない場合は寿命を勝手に補正せず、「メーカー確認が必要」と表示します。
